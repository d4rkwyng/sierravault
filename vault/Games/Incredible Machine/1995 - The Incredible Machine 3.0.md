# The Incredible Machine 3.0

<small style="color: gray">Last updated: October 13, 2026</small>

## Overview

The Incredible Machine 3.0 (also referred to as The Incredible Machine Version 3.0, and on some releases titled Professor Tim's Incredible Machines) is a puzzle video game developed by [[Dynamix]] and Jeff Tunnell Productions and published by [[Sierra On-Line]] in 1995 for Windows and Macintosh[^ref-2][^ref-21][^ref-23]. It is an enhanced version of The Incredible Machine 2: both games have the same levels, but Version 3.0 has an improved interface, CD music tracks and other additions[^ref-2][^ref-23]. MobyGames catalogues it as the Windows/Mac hybrid release of The Incredible Machine 2[^ref-21].

Like the rest of the series, it challenges players to build Rube Goldberg devices, arranging a given collection of objects in a needlessly complex fashion to perform a simple task[^ref-2]. The series was originally designed by Jeff Tunnell, whose Jeff Tunnell Productions developed it; Tunnell was the designer and producer, while Kevin Ryan designed and coded the games[^ref-2][^ref-13][^ref-16]. By 2000, the series had sold over one million copies[^ref-2].

The 2009 GOG.com compilation's description captures the premise: "Do you remember watching with amazement when those cartoon heroes constructed machines to catch someone or start something? Those very complicated Rube Goldberg-like ones with knives, toasters, anvils etc?"[^ref-15]

## Story Summary

The Incredible Machine 3.0, like its predecessors, has no narrative. Each level contains a machine designed to do a specific task, but parts are missing, and the player must work out where to put what to make the machine work[^ref-21]. Typical goals are simple tasks such as "put the ball into a box" or "start a mixer and turn on a fan"[^ref-2].

## Gameplay

### Interface and Controls

Version 3.0 uses the same levels as The Incredible Machine 2 but with an improved interface[^ref-2][^ref-23]. Players solve each puzzle by arranging a provided set of objects around fixed items that cannot be moved[^ref-2].

The game includes an editor for designing machines from scratch, either just for fun or as puzzles in which another player must fill in the missing parts[^ref-21]. The Incredible Machine 2 had extended the "freeform" mode so that players could define not only the participating parts but also the conditions under which a puzzle counts as solved[^ref-2][^ref-23].

### Structure and Progression

The level set is The Incredible Machine 2's, which introduced new levels, an extended assortment of parts and two-player hotseat play[^ref-2][^ref-23]. The Internet Archive's copy of the release describes "over 150 different machines" to construct, a "free-form" mode, and a "head to head" mode for playing against someone else[^ref-7].

### Puzzles and Mechanics

The series' engine does not use a random number generator in its physics simulation, so the results for any given machine are deterministic[^ref-2]. The games simulate physical interactions between objects as well as ambient effects such as air pressure and gravity[^ref-2].

Parts range from ropes and pulleys to electrical generators, bowling balls, cats and mice, many with specific interactions: mice run towards nearby cheese, and light placed next to a magnifying glass will ignite wicks[^ref-2]. MobyGames' description lists cats, super balls, lava lamps, flashlights, can openers and monkeys on treadmills among the parts[^ref-21].

## Reception

### Contemporary Reviews

According to Wikipedia, GameRankings recorded an aggregate score of 70% for The Incredible Machine Version 3.0[^ref-2]. MobyGames lists a critic average of 79% (15 ratings) for The Incredible Machine 2, an entry that also covers Version 3.0[^ref-21].

Reviewing The Incredible Machine 2, whose levels Version 3.0 shares, PC Gamer US's Gary Meredith wrote: "In every way, TIM2 is an improvement, keeping the best parts of the original yet giving the player more options and flexibility"[^ref-23]. The Incredible Machine 2 won Computer Gaming World's Readers' Choice award for the best "Classics/Puzzles" game of 1995[^ref-23].

### Modern Assessment

On MobyGames, the combined TIM 2/3.0 entry has a player average of 4.1 out of 5 from 57 ratings[^ref-21]. No dedicated modern critical retrospective of Version 3.0 was found in the sources consulted.

**Aggregate Scores:**
- **GameRankings (Version 3.0):** 70%[^ref-2]
- **MobyGames (TIM 2 / 3.0 entry):** 79% critics (15 ratings); 4.1/5 players (57 ratings)[^ref-21]

## Development

### Origins

According to Wikipedia, the first Incredible Machine was originally going to be developed by Electronic Arts for the Commodore 64 in 1984, but Dynamix worked on Arcticfox instead, and work on The Incredible Machine did not start until early 1993[^ref-2]. Jeff Tunnell, who had co-founded Dynamix in 1984 and left in 1990 to form Jeff Tunnell Productions, was the designer and producer of the original game, although he did not program it[^ref-13]. Kevin Ryan programmed the first game in nine months on a budget of about US$36,000[^ref-2]. Tunnell was granted a patent for the game concepts[^ref-16].

### Production

The 1993 through 1995 versions had the same development team[^ref-2]. Jeff Tunnell Productions' last titles, 3-D Ultra Pinball and The Incredible Machine 3.0, were released in 1995, before Dynamix took the studio over later that year[^ref-14].

### Technical Issues

The original release included CD-audio music, but the later digital re-release used MIDI instead; a fan patch on PCGamingWiki restores the CD soundtrack, noting that "The Incredible Machine 3 uses exactly the same soundtrack" as The Incredible Machine 2[^ref-12].

## Legacy

### Later Entries

The series continued with Return of the Incredible Machine: Contraptions (2000), which IGN described as "a vintage blend of educational and entertainment software at their finest" and which won the PC Family award at the 4th Annual Interactive Achievement Awards[^ref-2]. Jeff Tunnell's Contraption Maker (2014) is a spiritual successor to the series, made with Kevin Ryan and Brian Hahn of the original team[^ref-2].

### Collections

- **The Incredible Machine Mega Pack** (GOG.com, October 1, 2009) – includes Even More Incredible Machine, The Incredible Machine 3 (containing all levels from The Incredible Machine 2), Contraptions and Even More Contraptions[^ref-2][^ref-15]

The series' rights passed to Jeff Tunnell's PushButton Labs in 2009, and later to Disney after Playdom acquired PushButton Labs[^ref-2].
